# 仓库之夜脱衣扑克 · 中文版 (SPNATI zh)

基于 SPNATI 官方离线版 v13.72.0 制作的中文版，部署在 GitHub Pages 上用浏览器直接玩。

## 本版改动
- **中文界面**：新增简体中文语言包 `languages/zh.xml`（199 条界面字符串全译），并设为默认语言；设置里可切回 English / Español / 日本語。角色对话为社区英文原文，未翻译。
- **必赢外挂开关**：左下角红色按钮「必赢外挂：开/关」，默认开。开启时每局给玩家发同花大顺（10-J-Q-K-A 同花），换牌/摊牌前还会兜底，确保玩家不可能输。原理是调用游戏自带的 `Deck.rigFor()` 调试函数。
- **全角色图鉴**：`gallery.html`，收录全部 507 个角色，可按名字/出处/作者搜索，按性别和阵容筛选，点卡片看详情（出处、衣物层数、台词数、编剧/画师、简介）。

## 为什么仓库里没有角色图片
完整版 8.0G / 16.9 万文件，超过 GitHub 仓库与 Pages 的上限。本仓库只放游戏本体和角色的全部文本数据（826M），角色图片在打开时从官方站 spnati.net 直连加载，所以玩的时候需要联网。角色换装（reskins）数据未收入本仓库，设置里已关闭换装功能。

完整离线版（17 个官方包，含全部图片）另存于助手本地 `~/workspace/spnati/`。
